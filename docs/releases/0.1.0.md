Diskweft 0.1.0 is the first release of this independent SpaceScan fork.

- Live folder sizes, recursive file counts, extension totals and largest files during classic and NTFS scans.
- Stable keyboard navigation, selection and scrolling while scanning, with explicit partial, stopped, inaccessible and unresolved states.
- Windows 11 light/dark appearance, system or custom accent colors, high contrast and native window behavior.
- Independent settings, history, installer, shell routes and update feed. Installing Diskweft does not migrate or remove SpaceScan.
- Preserved search, duplicate detection, history/compare and CLI/CSV/HTML reports.

Verified on Windows 11 with real elevated NTFS, fallback, UNC, cancellation and restart. Three-pair baseline comparisons measured median overhead of 3.48% on the declared million-file classic fixture and 4.63% on the large NTFS volume. The million-file native check measured 12.4 ms p95 dispatcher latency. See the specification and S4 verification document for workload details and limits.

Download the installer or extract the portable ZIP. Keep Diskweft.exe.config beside the executable. Packages include MIT attribution and are unsigned (Authenticode NotSigned). Verify downloads against SHA256SUMS.txt.

NTFS raw access requires administrator rights. Results on actively changing volumes can remain incomplete when record ancestry cannot be resolved; those records are withheld rather than assigned invented paths. Older Windows versions have not been qualified.
