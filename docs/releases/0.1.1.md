Diskweft 0.1.1 restores automatic largest-first folder ordering while a scan runs. It uses current discovered sizes, keeps pending folders below measured results, and preserves selection, expanded folders and the visible scroll anchor.

The color scheme follows the supplied Windows Explorer references more closely without changing the layout: a dark tinted native title bar, warmer address surface, neutral selection, quieter borders and Windows-blue space bars. The system accent now comes from the Windows shell palette; custom accent and high-contrast support remain available. Low-space warnings remain red.

Release notes now show a text heading when no banner image is packaged, fixing first launch from an older Diskweft profile.

The installer and portable ZIP include the runtime DPI configuration and MIT notices. Binaries are unsigned (Authenticode NotSigned). Check downloads against SHA256SUMS.txt. Original SpaceScan history can be imported without rewriting its contents; its legacy completion status remains explicitly unknown.
